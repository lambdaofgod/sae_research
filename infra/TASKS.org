unlike the LLM =ActivationBuffer= which loops infinitely.

save block. Final checkpoint now records =actual_steps= instead of =steps=.

** DONE Resilient S3 download -- skip corrupt files instead of crashing
=dictionary_learning='s =_async_download()= sets =stop=True= and kills
the download worker when =torch.load= fails on a downloaded file (e.g.
truncated download via port-forward). This deadlocks the training loop
once the buffer drains.

Fix: subclass =S3RCache= in =sae_research= and override the download
loop so that corrupt files are logged and skipped, not fatal. The worker
should continue to the next file.

Temporal SAEs (from =forks/temporal-saes/=) train on pairs of consecutive

preempted by Kueue, it restarts from scratch. Need a =--resume= flag that
loads =ae.pt= + optimizer and continues from the saved step.
