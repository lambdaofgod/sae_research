#+title: SAE Research

* Overview

Apply sparse coding / dictionary learning algorithms to pretrained SAE decoder matrices — greedy/thresholding methods with theoretical guarantees (RIP, mutual coherence) to control sparsity at inference time without retraining.

* Repository layout

- =sae_research/= — Python package: inference-side SAE classes, modules, adapters, loaders
- =dictionary_learning_saes/= — Trained nested thresholding top-k SAE checkpoints
- =experiments/= — Subdirectories for specific experiments (sae_bench, embedder_sae, SSC, etc.)
- =../forks/dictionary_learning_demo/= — Fork of adamkarvonen/dictionary_learning_demo with custom trainers

* Running training

All training requires S3 credentials from the K8s cluster. Wrap every training
command with =scripts/with-k8s-env.sh= — it reads credentials from the cluster
and starts port-forwards for S3 and MLflow:

#+begin_src sh
bash scripts/with-k8s-env.sh uv run python -m sae_research.training.runner --config configs/temporal_sae_small.yaml
#+end_src

Without the wrapper you'll get a =ValueError= about missing =AWS_ACCESS_KEY_ID=.
Configs are in =configs/=; use =temporal_sae_small.yaml= (20M tokens) to smoke-test
and =temporal_sae.yaml= (200M tokens) for a full run.
